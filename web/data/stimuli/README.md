# Stimuli layers

## core/ (prefer for product path)
- Open Peeps / Humaaans (CC0)
- Own SVG/pattern tasks in the UI (`VisualCard`)

## extra/ (private enrichment, swappable)
- `pse/` — Picture Story Exercise images (per-image license table)
- `oasis/` — OASIS affective images (NC / research; private only)
- `pdii/` — pictorial interest images if obtained

Drop downloaded assets into the matching folder. Keep a sidecar JSON with:
`id`, `sourceId`, `license`, `attribution`, `layer`.
